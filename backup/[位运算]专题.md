## 一、 整数的底层位序列与补码数学机理

位序列在计算机中分为有符号（Signed）和无符号（Unsigned）两种映射规则。

在现代计算机架构下，有符号整数严格采用**补码（Two's complement）**表示。网络上很多博客（包括一些早期的教材）对负数补码的描述有误，真正的核心数学性质你只需要记住这一条：
对于 $N$ 位有符号整数 $x$，其补码的代数真值严格满足：

$$
-x = \sim x + 1
$$

这一性质是后续所有“最低位提取（lowbit）”技巧的数学基石。

> **【排雷预警：C++ 标准中的未定义行为 UB】**
> 1. **负数左移**：在 C++20 之前，对负数进行左移（`<<`）是严格的未定义行为（UB）。
> 2. **越界移位**：移位位数大于等于类型的位宽（如对 `int32` 左移 32 位），属于 UB，其结果在开启 `-O2` 优化下完全不可控。
> **工程与竞赛规范**：位运算请尽量使用无符号类型（如 `1ull << i`）。

## 二、 核心位运算符与优先级陷阱

位运算符的优先级极易引起逻辑坍塌，记住这个宏观顺序（由高到低），**强烈建议写宏定义或复杂逻辑时无脑加括号**。

| 运算符 | 符号 | 优先级位面 | 核心运算法则 |
|---|---|---|---|
| 按位取反 | `~` | 第一梯队（最高） | $0 \mapsto 1$，$1 \mapsto 0$ |
| 左移 / 右移 | `<<`, `>>` | 第二梯队 | 左移补 0；**有符号数右移补符号位，无符号数右移补 0** |
| 按位与 | `&` | 第三梯队 | 满足 `a & a = a`、`a & 0 = 0` |
| 按位异或 | `^` | 第四梯队 | 不进位加法。满足 `a ^ a = 0`、`a ^ 0 = a` |
| 按位或 | `\|` | 第五梯队（最低） | 满足 `a | a = a`、`a | 0 = a` |

*(注：表格中的 `|` 为防止解析错误，写为转义形式 `\|`，实际代码中即为按位或)*

## 三、 实用位运算高级操作速查表 (Cheat Sheet)

在处理状态压缩 DP 时，我们经常需要对数字的各个二进制位进行精细的“外科手术”。以下整理了竞赛中最常用的位运算 $O(1)$ 变换技巧（注：以下操作假设第 $k$ 位是从右往左数，下标从 1 开始）。

### 1. 基础位操作
| 功能需求 | 位运算表达式 | 逻辑原理解析 |
| :--- | :--- | :--- |
| **去掉最后一位** | `x >> 1` | 整体右移，最低位直接被丢弃。 |
| **在最后加一个 0** | `x << 1` | 整体左移，右侧自然补 0。 |
| **在最后加一个 1** | `(x << 1) \| 1` | 左移后末尾为 0，与 1 进行或运算即可置 1。 |
| **将最后一位变为 1** | `x \| 1` | 利用 `0 | 1 = 1`, `1 | 1 = 1` 的覆盖性质。 |
| **将最后一位变为 0** | `x & ~1` | 严格写法。网上也有用 `(x | 1) - 1` 的，但位运算屏蔽比加减法更安全。 |
| **最后一位取反** | `x ^ 1` | 利用异或性质，除最后一位外其余保持不变。 |
| **将右数第 $k$ 位变为 1** | `x \| (1 << (k - 1))` | 构造第 $k$ 位为 1 的掩码，进行按位或。 |
| **将右数第 $k$ 位变为 0** | `x & ~(1 << (k - 1))` | 构造第 $k$ 位为 0、其余为 1 的掩码，进行按位与。 |
| **将右数第 $k$ 位取反** | `x ^ (1 << (k - 1))` | 利用 `1 ^ 1 = 0`, `0 ^ 1 = 1` 定点翻转。 |

### 2. 连续位与区间操作
| 功能需求 | 位运算表达式 | 逻辑原理解析 |
| :--- | :--- | :--- |
| **取末尾 $k$ 位** | `x & ((1 << k) - 1)` | `(1<<k)-1` 会生成一个后 $k$ 位全为 1 的掩码（如 $k=3$ 得到 `0111`）。 |
| **取右数第 $k$ 位的值** | `(x >> (k - 1)) & 1` | 将目标位推到最低位，然后屏蔽其他高位。 |
| **把末尾 $k$ 位全变为 1** | `x \| ((1 << k) - 1)` | 直接将末尾 $k$ 位用全 1 掩码覆盖。 |
| **把末尾 $k$ 位取反** | `x ^ ((1 << k) - 1)` | 用全 1 掩码进行异或。 |
| **把右边连续的 1 变为 0** | `x & (x + 1)` | 加 1 会让连续的 1 产生链式进位变成 0，再做与运算彻底清零。如 `0111 -> 0000`。 |
| **把右起第一个 0 变为 1** | `x \| (x + 1)` | 原理同上，加 1 翻转连续 1 及其左侧的第一个 0，然后利用或运算保留原有的 1。 |
| **把右起连续的 0 变为 1** | `x \| (x - 1)` | 减 1 会让连续的 0 借位全变 1。 |
| **取右边连续的 1** | `(x ^ (x + 1)) >> 1` | 提取出连续的 1 的区间，移位修正。 |
| **去掉右起第一个 1 的左边** | `x & -x` | 即鼎鼎大名的 **lowbit** 操作。原式 `x & (x ^ (x - 1))` 等价于 `x & -x`，但后者利用补码性质，指令更短。 |

## 四、 考点升华：算术运算与位运算的等价代换

这是区域赛最喜欢考察的脑洞点。很多题目看似是求加减法，其实需要转成位运算独立拆位处理；反之亦然。

### 1. 基础容斥原理（Inclusion-Exclusion on bits）
对于任意两个整数 $a$ 和 $b$，它们的按位或、按位与、按位异或与算术加法之间，存在严格的代数恒等式：

$$
a + b = (a \text{ OR } b) + (a \text{ AND } b)
$$

$$
a \text{ OR } b = (a \oplus b) + (a \text{ AND } b)
$$

联合上面两式，可以推导出异或与加法的终极关系（**半加器原理**）：

$$
a + b = (a \oplus b) + 2 \times (a \text{ AND } b)
$$

或者写成移位形式：

$$
a + b = (a \oplus b) + ((a \text{ AND } b) \ll 1)
$$

**考点应用**：如果题目给定 $a \oplus b = X$ 和 $a \text{ AND } b = Y$，让你求 $a$ 和 $b$ 的解数。你不仅能立刻算出 $a+b = X + (Y \ll 1)$，还可以利用前提条件 $(a \oplus b) \text{ AND } (a \text{ AND } b) = 0$ 来快速判断是否有解（若 $X \text{ AND } Y \neq 0$ 则必定无解）。

### 2. 区间异或性质
计算从 1 到 $n$ 的连续异或和存在 $O(1)$ 的周期律。设 $f(n)$ 为前 $n$ 个数的异或和：
*   $n \bmod 4 = 0 \implies f(n) = n$
*   $n \bmod 4 = 1 \implies f(n) = 1$
*   $n \bmod 4 = 2 \implies f(n) = n + 1$
*   $n \bmod 4 = 3 \implies f(n) = 0$

## 五、 状态压缩与常数优化极致

### 1. 严谨的 $O(3^N)$ 子集枚举
遇到状压 DP 需要枚举当前集合 `x` 的所有子集 `y` 时，下面的写法能跳过所有非法状态：

```cpp
void solve()
{
    ll n;
    cin >> n;
    for (int x = 0; x < ((ll)1 << n); x++)
    {
        for (int y = x;; y = x & (y - 1))
        {
            cout << y << " ";
            if (!y)
                break;
        }
        cout << endl;
    }
}
```
原理：y - 1 会把最低位的 1 变成 0，右侧变 1。再通过 & x 过滤，强制将不属于该母集的位剔除。根据二项式定理 $\sum_{k=0}^n \binom{n}{k} 2^k = 3^n$，这两重循环的总时间复杂度严格收敛于 $O(3^N)$，没有任何冗余计算。

2. 构造汉明权重递增的排列 (Gosper's Hack)这是一个神级代码。给定一个整数 $x$，它能在 $O(1)$ 时间内计算出下一个比 $x$ 大，且二进制中 $1$ 的个数（汉明权重）与 $x$ 完全相同的数。 

```cpp
typedef long long ll;
// 依赖宏定义：#define lowbit(x) ((x) & (-x))
ll wk(ll x) {
    int c = lowbit(x);                 // 步骤 1
    int r = x + c;                     // 步骤 2
    return (((r ^ x) >> 2) / c) | r;   // 步骤 3
}
```
**算法原理极其精妙，我们像剥洋葱一样拆解它：**
假设 $x$ 的二进制表示中，最右侧连续的 1 的区块为 `...011100...`（假设有 $k$ 个 1）。
1. **`c = lowbit(x)`**：提取出这块连续 1 的最低位（如上面的最右边的 1）。
2. **`r = x + c`**：由于加法进位，最右侧的连续的 1 会发生多米诺骨牌式的翻转。原本 `...011100...` 会变成 `...100000...`。
    * *代价*：此时我们失去了一个由 $k$ 个 1 组成的区块，只换来了一个更高位的 1。总体上，数变大了，但是我们损失了 $k-1$ 个 1。我们需要把这缺失的 $k-1$ 个 1 补偿到**二进制的最最末尾**，才能保证得到的数不仅汉明权重相同，而且是“仅大于 $x$”的最小值。
3. **`(((r ^ x) >> 2) / c) | r`**：这是找回那 $k-1$ 个 1 的过程。
    * `r ^ x`：原区块是 `011...`，现在是 `100...`，两者异或后会得到 `111...`。即提取出了刚刚发生翻转的所有位，恰好是 $k+1$ 个 1。
    * `>> 2`：将 $k+1$ 个 1 右移 2 位，恰好去掉了 2 个 1，现在手里正好握着我们要补偿的 **$k-1$ 个 1**。
    * `/ c`：因为 `c` 是 2 的幂，除以 `c` 在底层的等价操作就是向右移位。这一步直接把那 $k-1$ 个 1 狠狠地推到了二进制的最右侧边缘（第 0 位开始）。
    * `| r`：最后，把排列好的 $k-1$ 个 1 和之前进位后的 `r` 拼装（按位或）在一起。完美达成目标！

**核心应用场景：**
* **$O(1)$ 枚举组合数**：当我们需要在 $N$ 个物品中恰好选 $K$ 个物品（相当于枚举所有长度为 $N$、包含 $K$ 个 1 的状态）时，直接用 `wk(x)` 不断跳转。不用写任何 DFS 递归，常数小到离谱！
* **定长状态 DP**：例如在旅行商问题 (TSP) 中，当我们想按照“已访问过 3 个城市”、“已访问过 4 个城市”来对状态进行严格的分层转移时，Gosper's Hack 就是最高效的状态生成器。

### 3. GCC 内建函数
调用底层汇编指令，效率远超市面上的手写循环。
*   `__builtin_popcount(x)`：返回二进制中 1 的个数。（64 位需用 `__builtin_popcountll`）
*   `__builtin_ctz(x)`：返回末尾连续 0 的个数。**注意 $x=0$ 时为 UB。**
*   `__builtin_clz(x)`：返回前导连续 0 的个数。**注意 $x=0$ 时为 UB。**

## 六、 进阶数据结构一：0-1 Trie (字典树) 解决异或最值

当题目要求在一个动态维护的集合中，寻找与给定数 $x$ 异或结果最大（或最小）的元素时，0-1 Trie 是最锐利的武器。

**算法原理**：
将所有的数字看作长度为 31（或 63）的二进制字符串，插入到字典树中。在查询给定数字 $x$ 的最大异或对时，采用**贪心策略**：从最高位开始向下走，如果存在与 $x$ 当前位**相反**的子节点，就必须走相反的节点（这样异或出来的这一位才是 1，高位的 1 比低位所有的 1 加起来都要大）；如果不存在相反的节点，才被迫走相同的节点。

**个人精简版模板 (解决最大异或对)**：
*使用了静态数组 `son[N*31][2]` 来动态开点，常数极小。*

```cpp
#include <bits/stdc++.h>
using namespace std;
// CJX__//
typedef long long ll; // 不开long long 见祖宗
typedef unsigned long long ull;
typedef __int128 i128;
typedef pair<int, int> PII;
typedef pair<ll, ll> PLL;
typedef vector<int> vi;
typedef vector<ll> vll;
typedef vector<double> vd;
typedef vector<PII> vPII;
#define IOS                  \
    ios::sync_with_stdio(0); \
    cin.tie(0);              \
    cout.tie(0);
#define debug(...) cout << "[debug] " #__VA_ARGS__ " = " << (__VA_ARGS__) << endl;
#define out(x) cout << ((x) ? "YES" : "NO") << endl
#define mod(x, P) (((x) % (P) + (P)) % (P))
#define endl '\n'
#define gcd __gcd
#define lowbit(x) ((x) & (-x))
#define rep(i, x, n) for (ll i = x; i <= n; i++)
#define dep(i, x, n) for (ll i = x; i >= n; i--)
#define mem(a, x) memset(a, x, sizeof a)
const int N = 1e5 + 10;

ll n;
ll a[N];
int son[N*31][2];
int idx;

// 插入一个数字的二进制表示
void insert(ll x)
{
    int p = 0;
    for (int i = 31; i >= 0; i--)
    {
        if (!son[p][(x >> i) & 1])
            son[p][(x >> i) & 1] = ++idx;
        p = son[p][(x >> i) & 1];
    }
}

// 贪心查询集合中与 x 异或和最大的结果
ll query(ll x)
{
    ll ret = 0;
    int p = 0;
    for (int i = 31; i >= 0; i--)
    {
        ll now = (x >> i) & 1;
        // 优先尝试走与当前位相反的分支（异或后该位为 1）
        if (son[p][now ^ 1])
        {
            ret += ((ll)1 << i);
            p = son[p][now ^ 1];
        }
        else
        {
            p = son[p][now];
        }
    }
    return ret;
}
```

## 七、 进阶数据结构二：线性基 (Linear Basis) 与第 $k$ 小异或和

线性基是集合在 $\text{GF}(2)$ 向量空间下的一组极大线性无关组。通俗地说，原数组能异或出来的任何数字，线性基也能异或出来；且线性基是满足这个条件的**最小集合**。

除了求最大异或和，线性基在 ICPC/CCPC 赛场上最经典的考点是：**求异或和的第 $k$ 小值**。这需要我们不仅能 `insert`，还要能对线性基进行**重构 (rebuild)**。

**算法原理 (Rebuild 机制)**：
1. 普通的 `insert` 构造出的线性基，虽然能表出所有元素，但不同基元素之间可能会互相干扰（例如 $p[i]$ 的第 $j$ 位可能是 1，而 $p[j]$ 也有值，导致异或后大小不可控）。
2. `rebuild` 过程类似于线性代数中的**高斯消元化简为简化阶梯型矩阵**。它用低位的基去消去高位基中的 1。重构后，对于任何基底 $d[i]$，只要你选了它，异或和就必然严格增大，彼此绝对独立。
3. 查询第 $k$ 小时，只需将 $k$ 转化为二进制，若第 $i$ 位为 1，就异或上重构后的第 $i$ 小基底 $d[i]$ 即可。注意特判原数组能否异或出 0（即 `zeros` 标记）。

**个人标准模板 (支持插入、重构与查询第 K 小)**：

```cpp
#include <bits/stdc++.h>
using namespace std;
// CJX__//
typedef long long ll; 
// ... (此处省略个人的 typedef 和宏定义缺省源) ...

/*
经典例题：[https://www.luogu.com.cn/problem/P3812](https://www.luogu.com.cn/problem/P3812)
*/
ll p[65];
ll d[65];
ll a[N];
int cnt = 0;
int len = 0;
bool zeros = false;

// 贪心插入元素，构造初步线性基
void insert(ll x)
{
    for (int i = 60; i >= 0; i--)
    {
        if ((x >> i) & 1)
        {
            if (!p[i])
            {
                p[i] = x;
                cnt++;
                return;
            }
            x ^= p[i];
        }
    }
}

// 重构线性基 (化为简化阶梯型)，提取出严格递增的独立基底存入 d 数组
void rebuild(int n)
{
    for (int i = 60; i >= 0; i--)
    {
        if (p[i])
        {
            // 用较小的基底去消减较大的基底
            for (int j = i - 1; j >= 0; j--)
            {
                if (p[j] && ((p[i] >> j) & 1))
                {
                    p[i] ^= p[j];
                }
            }
        }
    }
    len = 0;
    for (int i = 0; i <= 60; i++)
    {
        if (p[i])
        {
            d[len++] = p[i];
        }
    }
    // 如果插入成功的基底数量 cnt 小于总元素数量 n，说明有元素被完全消为 0，即可以异或出 0
    zeros = (cnt != n); 
}

// 查询异或出的第 k 小值
ll query_kth(ll k)
{
    if (zeros)
    {
        if (k == 1) return 0; // 如果能异或出 0，第 1 小就是 0
        k--; // 排除掉 0 的排名，继续在正数中找
    }
    if (k >= ((ll)1 << len)) return -1; // k 超出可表出的集合总数
    
    ll res = 0;
    for (int i = 0; i < len; i++)
    {
        // 根据 k 的二进制表示，直接决定是否选取该基底
        if ((k >> i) & 1)
        {
            res ^= d[i];
        }
    }
    return res;
}
```
## 九、 进阶拓展二：SOS DP (高维前缀和 / 快速莫比乌斯变换)

我们在前文讲到了用 `for (int sub = mask; sub; sub = (sub - 1) & mask)` 进行 $O(3^N)$ 的子集枚举。
但在区域赛中，如果 $N = 20$，状态总数 $2^{20} \approx 10^6$，此时 $O(3^N) \approx 3.48 \times 10^9$ 会直接 TLE（超时）。

当题目要求对所有状态 $S$，求出其所有子集 $sub$ 的权值之和（即 $F[S] = \sum_{sub \subseteq S} A[sub]$）时，我们需要利用**高维前缀和 (Sum Over Subsets, SOS DP)** 技巧，将时间复杂度从 $O(3^N)$ 降维打击到 $O(N \cdot 2^N)$。

**算法原理**：
把一个长度为 $N$ 的二进制状态看成一个 $N$ 维空间中的点。求子集和，本质上就是在求这个 $N$ 维空间的前缀和。我们可以像一维、二维前缀和那样，逐个维度（逐个二进制位）进行累加推平。

**极简代码模板**：
```cpp
// 假设 a 数组存放初始值，我们需要求出 f 数组，f[mask] 表示 mask 所有子集的 a 权值之和
for (int i = 0; i < (1 << n); ++i) f[i] = a[i];

// 依次枚举每一个二进制位 (也就是每一个维度)
for (int i = 0; i < n; ++i) {
    for (int mask = 0; mask < (1 << n); ++mask) {
        // 如果 mask 的第 i 位是 1，那么它必须包含第 i 位为 0 的对应子集状态的贡献
        if ((mask >> i) & 1) {
            f[mask] += f[mask ^ (1 << i)];
        }
    }
}
```
